# TRS-80_B-17 Documents Folder

Documents and publications related to ABS Suppliers B-17 Tape System for the TRS-80 Model I

## Contents:

### Manuals:

Unfortunately, I was not able to locate a manual for the B-17 system, however, some aspects
of usage are covered in the reviews.

I will try to make an effort to write a "How to Use" section in the near future.

### Reviews

I was able to find two reviews in magazines from the period:

1. [A review in The Alternate Source magazine, Volume 1 Number 2](Reviews/Review_The_Alternate_Source_Vol1_No2_page19-21.pdf).
This review describes the B-17 program, how it works, and its pros and cons with a brief overview on how
to use it.

2. [A review in 80 Microcomputing from March 1981](Reviews/Review_B17_80_Micro_1981-03.pdf). This review
was written and published as though it were its own article, which makes it quite detailed and inofrmative,
but unfortunately, as it was not filed in the "Reviews" section of the magazine, it failed to appear in the
annual index of articles and reviews. i was only able to find it thanks to a special review issue of 80 Micro.


### Advertisements in 80 Microcomputing Magazine:

B-17 was advertised in 80 Micro every month from November 1981 to December 1982, with roughly the same format each
time: one-ninth of a page (i.e. one box in a 3-by-3 grid on a single page).  The ads themselves only varied
slightly, changing address and pricing, and listing three products:

1. B17 Tape Operating System
2. B17 DISK/BAS (for backups to tape of disk files)
3. Wordsmith word processor (written in BASIC)

In the December 1982 advertisement, "B17 DISK/BAS" was replaced with "MICRO-SCOPE" diagnostics
program for disk systems.
